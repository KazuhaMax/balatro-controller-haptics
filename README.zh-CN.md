# 小丑牌手柄增强｜Balatro Controller Haptics

为 Steam 桌面版《Balatro》增加短促、及时的手柄震动反馈。

[English](README.md) · [下载最新版](https://github.com/KazuhaMax/balatro-controller-haptics/releases/latest) · [反馈问题](https://github.com/KazuhaMax/balatro-controller-haptics/issues)

这个 Lua mod 将菜单、出牌及计分事件转成短促的震动脉冲，改善持续拖尾和菜单反馈迟钝的问题。

**v1.3.2**：新增 PlayStation、Nintendo、Xbox 按键图标的自动识别与手动切换，包含 1.3.1 的火焰及手柄导航修复；新配置默认均衡，火焰开启。无需 Lovely 或 Steamodded 前置。

## Windows 安装

1. 解压 `balatro-controller-haptics-1.3.2.zip`。
2. 完全退出 Balatro。
3. 按 **Win + R**，输入 `%AppData%\Balatro`，按回车。如果目录不存在，先启动一次游戏并退出。
4. 把 **`main.lua` 和 `controller_haptics.lua`** 复制到这个文件夹，与 `settings.jkr` 放在同一层。
5. 用 USB 连接 DualSense 或 Xbox 手柄，从 Steam 启动游戏。
6. 在 **设置 → 游戏 → 控制器震动** 中先选择 **中**。

不需要额外安装 mod 加载器，也不要把文件放进 `Mods` 子目录。更新本 mod 时，退出游戏后替换这两个文件即可。

如果已有 `main.lua` 属于其他 mod，请先备份并合并加载器，避免直接覆盖。

## macOS 安装

退出游戏，在 Finder 中按 **Command + Shift + G**，打开：

```text
~/Library/Application Support/Balatro
```

把相同的两个 Lua 文件放到 `settings.jkr` 旁边，重启游戏后调整震动强度。

## 自定义震动

入口：**设置 → 游戏 → 详细设置**，就在震动强度下方；震动风格移至详细设置内。
新配置默认使用均衡，火焰开启。已有设置会保留；升级后若要使用新默认值，请应用“均衡”，并在“计分火焰反馈”中开启火焰增强。

- **分类事件菜单：** 18 类事件分为菜单、卡牌、计分、金币与盲注、标题五组。每个事件可单独开关，调整强度（25–200%）、时长（50–150%）及左右混合，并提供预览和单项重置。
- **左右混合：** 原始比例、偏右（轻）、双侧均衡、偏左（重）、双侧全量。调整的是普通震动的两个通道，实际轻重感取决于手柄。
- **预设与保存槽位：** 仅保留均衡（默认）和柔和两种预设，另有三个自定义槽位。均衡使用双侧均衡、125% 事件时长；柔和使用原始左右比例、75% 时长与 75% 额外增益。应用内置预设会保留设备选择、左右微调及火焰设置。保存包含事件、手柄和火焰设置，会替换所选槽位；载入空槽不会修改设置。总震动强度及事件／简洁风格不包含在槽位内。设置使用游戏原有的 `settings.jkr` 保存，无需额外配置文件。
- **手柄微调：** 自动、Xbox／通用、DualSense、其他 Sony 四种设备预设；额外增益和左右强度分别可调 50–150%，附左右通道测试。Steam Input 把 DS5 显示成 Xbox 时可手动选择 DualSense。这是手动调校，不是自动硬件校准或原生音频触觉。
- **按键图标：** 在 **详细设置 → 按键图标** 中选择自动（默认）、PlayStation、Nintendo 或 Xbox，并查看即时预览。自动识别 Sony/Nintendo 厂商编号以及 DualSense、DualShock、Switch、Joy-Con 名称。Steam Input 隐藏真实型号时，可手动指定。Nintendo 默认按下／右／左／上显示 B/A/Y/X；如果 Steam Input 重映射导致字母不符，选择“A/B 与 X/Y 互换”。此设置更新全游戏的按键提示，不改变实际输入，独立于震动预设和保存槽位。
- **计分火焰反馈：** 当前显示的手牌筹码 × 倍率达到盲注目标后，产生独立的短促节奏，无需等待新的计分音效。每次约 55 毫秒，间隔 100–150 毫秒触发。计分事件增强在达到目标时为所选上限的一半，4 倍目标时达到上限。最大幅度可选 +25%、+50%、+100%，同时影响火焰节奏的力度。暂停、打开菜单或离开计分时停止，不支持的大数对象会跳过。

事件自定义和火焰反馈仅适用于“事件”风格；手柄微调也适用于“简洁”。用手柄操作预览按钮；关闭总震动、失焦或断连时仍保持静音。最终输出上限为 100%，过强的设置可能让不同事件都触及上限，削弱层次。

## 不安装前置也能运行的原理

它本身就是 mod，只是自带一个很小的加载器。在这个桌面版本中，LÖVE 优先查找 Balatro 存档目录中的文件，因此我们的 `main.lua` 会先运行。它临时切换搜索顺序，加载游戏自带的原始 `main.lua`，再恢复搜索顺序、运行原入口，最后载入 `controller_haptics.lua`。

震动脚本包装原有的游戏事件、逐帧更新和界面函数，在保留原逻辑的同时，通过 LÖVE 的 `Joystick:setVibration` 向 SDL 和手柄发送震动。设置页面也由游戏自带的 UI 函数生成，不需要修改游戏可执行文件或安装其他 mod 框架。

## 基础反馈行为

- 新增 **震动风格 → 事件／简洁**。默认“事件”；“简洁”保留 1.1 的通用短脉冲手感，可随时切换比较。
- 分类反馈覆盖菜单移动与确认、抽牌、出牌、筹码、倍率、乘倍率、版本计分、金币、结算总额、减益、销毁、碎牌、盲注揭示和标题效果。各类使用独立的时长及左右强度预设。
- 直接观察菜单焦点变化，并借助游戏音效调用识别其他事件；游戏静音时仍能反馈。音效映射是近似分类，可能覆盖额外的同名音效场景。
- 同帧同类事件合并；已分类事件替代该帧通用反馈，避免双重触发。未识别且带有原版震动信号的事件仍使用通用脉冲。
- 菜单操作和游戏事件处理完成后，在当前帧输出震动。
- 脉冲按真实时间计时，长度由预设与单项事件时长设置调整。
- 屏幕抖动每次新增冲击只触发一次反馈，视觉拖尾不会不断补充震动。
- 原始左右比例侧重高频细节，均衡则使用相同的左右通道强度；识别到 DualSense 时使用 1.4 倍增益，是预览版 0.7 的两倍指令强度（达到输出上限时会限幅）；Xbox／通用手柄仍为 1.0，其他 Sony 手柄仍为 0.7。
- 切换窗口、切换控制器、断连、关闭震动及退出时停止反馈。
- 每条非零震动指令最多持续 120 毫秒，避免游戏卡住时留下无限震动。
- 保留关、弱、中、强、最强五档，以及已有设置。

这是普通双马达震动，不实现 iOS 原生触觉模式、Switch HD Rumble 波形、DualSense 音频触觉或自适应扳机。

事件预设是自行调校的效果，不是提取的官方参数。“事件分类”不等于“还原官方手感”。若参考的是 iOS 连接手柄的反馈，建议用同一只手柄对照菜单移动、抽牌、连续计分和结算，再逐项调校。两种模式都保留 120 毫秒指令超时、失焦及断连停止保护。

## 常见问题

- **没有“控制器震动”选项：** 检查两个 Lua 文件是否直接放在 `settings.jkr` 旁边，并完全重启游戏。可查看同目录的 `controller_haptics.log`。
- **有选项但不震：** 按一下手柄按钮，让游戏切换到手柄输入；确认震动未关闭，优先使用 USB 连接。
- **DualSense 被识别为 Xbox：** Steam Input 可能改变游戏看到的设备身份。如果完全不震，可以尝试仅为 Balatro 关闭 Steam Input 后重启；若手柄无法操作，再恢复原设置。自动模式下，虚拟 Xbox 身份会使用通用强度；可在 **详细设置 → 手柄与左右强度 → 设备预设** 中手动选择 DualSense。
- **强弱不合适：** 先调整总震动强度，再通过详细设置调整手柄增益或单项事件。
- **提交问题：** 请提供系统、游戏版本、手柄型号、USB/蓝牙、Steam Input 状态及相关日志。

## 卸载

退出游戏，删除本 mod 的 `main.lua` 和 `controller_haptics.lua` 即可。不要删除 `settings.jkr` 或数字命名的存档目录。回退旧版时，恢复备份的两个 mod 文件并重启。
